## 🇺🇸 English

A community collection of anime wallpapers, great for desktops, phones and custom Discord themes (like [midnight](https://github.com/refact0r/midnight-discord)).

### Structure

```
anime_wallpaper/
├── wallpapers/     # approved images
└── README.md
```

### Using a wallpaper

Open an image in the repository, click **Raw** (or **Download**) and use the direct link. Example for a Discord theme:

```css
--background-image: on;
--background-image-url: url('https://raw.githubusercontent.com/MoacirJr10/anime_wallpaper/main/wallpapers/IMAGE_NAME.png');
```

###  Contributing

Contributions are welcome! **Every submission is reviewed by the maintainer before being merged**, so nothing is published automatically.

1. **Fork** this repository.
2. Add your image to the `wallpapers/` folder.
3. Open a **Pull Request** with:
   - the artist's name or the source link (credit is required);
   - a short description (series/character, if any).
4. Wait for review. I may ask for changes or decline an image.

###  Rules

- **Only submit images you have the right to share.** If you are not the artist, include the original source and credit.
- If an artist asks for their work to be removed, it will be removed.
- **No NSFW, gore, hateful or offensive content.**
- Preferred formats: `.png`, `.jpg` or `.webp`.
- Recommended resolution: **1920×1080 or higher**, ideally under **5 MB** (large files make themes slow).
- File names in lowercase, no spaces, words separated by `_` (e.g. `night_city_rain.png`).
- No duplicates: check the folder before submitting.

###  License / Credits

All images belong to their respective artists. This repository only organizes and shares them for personal use. If you are the owner of an image and want it removed or credited, please open an **Issue**.

## 🇧🇷 Português

Uma coleção colaborativa de wallpapers de anime, ótima para desktop, celular e temas personalizados do Discord (como o [midnight](https://github.com/refact0r/midnight-discord)).

###  Estrutura

```
anime_wallpaper/
├── wallpapers/     # imagens aprovadas
└── README.md
```

###  Como usar um wallpaper

Abra a imagem no repositório, clique em **Raw** (ou **Download**) e use o link direto. Exemplo para um tema do Discord:

```css
--background-image: on;
--background-image-url: url('https://raw.githubusercontent.com/MoacirJr10/anime_wallpaper/main/wallpapers/NOME_DA_IMAGEM.png');
```

###  Como contribuir

Contribuições são bem-vindas! **Toda imagem enviada é analisada pelo mantenedor antes de ser aceita**, então nada é publicado automaticamente.

1. Faça um **Fork** deste repositório.
2. Adicione sua imagem na pasta `wallpapers/`.
3. Abra um **Pull Request** com:
   - o nome do artista ou o link da fonte (o crédito é obrigatório);
   - uma breve descrição (série/personagem, se houver).
4. Aguarde a análise. Posso pedir alterações ou recusar a imagem.

###  Regras

- Se um artista pedir a remoção da obra, ela será removida.
- **Sem conteúdo NSFW, gore, de ódio ou ofensivo.**
- Formatos preferidos: `.png`, `.jpg` ou `.webp`.
- Resolução recomendada: **1920×1080 ou maior**, de preferência com menos de **5 MB** (arquivos grandes deixam os temas lentos).
- Nomes de arquivo em minúsculas, sem espaços, com palavras separadas por `_` (ex.: `cidade_noite_chuva.png`).
- Sem duplicatas: confira a pasta antes de enviar.

### Licença / Créditos

Todas as imagens pertencem aos seus respectivos artistas. Este repositório apenas organiza e compartilha as imagens para uso pessoal. Se você é dono de alguma imagem e quer que ela seja removida ou creditada, abra uma **Issue**.
